# sankalp-x

AI orb for judicial and financial queries. Voice-driven over a benchmarked retrieval backend.

## Why this exists

General-purpose assistants answer judicial and financial questions vaguely. sankalp-x grounds answers in a domain corpus and exposes them through a voice-first orb, so a non-technical user can ask aloud and get a sourced response.

## What it does

- Answers judicial and financial queries from a retrieval backend.
- Accepts voice input and responds conversationally.
- Includes a voice-latency benchmark harness.

## Stack

Next.js · Python · retrieval backend · speech I/O
